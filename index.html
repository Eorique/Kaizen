改善

Filosofia de "Melhoria Contínua"

Kaizen é uma palavra japonesa que significa "mudar para melhor" ou "melhoria contínua". Na indústria e na tecnologia, representa a busca constante por eliminar desperdícios de tempo, falhas e tarefas repetitivas sem valor agregado.

Na saúde, o tempo digitando prontuários é um desperdício que afasta o médico da atenção ao ser humano. O robô foi batizado como Projeto Kaizen porque aplica essa filosofia na rotina médica: pequenas automações diárias resultam em uma enorme evolução na qualidade do atendimento hospitalar.

ARQUITETURA DO FLUXO DE FUNCIONAMENTO

Entenda o caminho que os dados percorrem desde a fala do médico até o preenchimento da ficha:

ETAPA 1

Captura Multimodal

O médico fala os sintomas e prescrições. O microfone USB do TJBot capta o áudio em alta fidelidade.

ETAPA 2

Processamento Local

O Raspberry Pi 3 B+ processa o sinal de áudio e ativa o LED RGB indicando recepção de comandos.

ETAPA 3

Motor de I.A.

A IA realiza o processamento de linguagem natural (NLP), convertendo a fala em JSON estruturado.

ETAPA 4

Prontuário & Feedback

A ficha do paciente é preenchida no sistema e o alto-falante/servo motor do robô confirma a ação.

Captura de imagem e leitura de documentos via OpenCV (camera.py)
import cv2

def capturar_documento():
    camera = cv2.VideoCapture(0)
    print("[TJBot] Capturando imagem do documento...")
    ret, frame = camera.read()
    if ret:
        cv2.imwrite("documento_paciente.jpg", frame)
        print("[TJBot] Imagem salva com sucesso!")
    camera.release()

if __name__ == "__main__":
    capturar_documento()
Captura de voz e conversão em texto (microphone.py)
import speech_recognition as sr

def ouvir_medico():
    recognizer = sr.Recognizer()
    with sr.Microphone() as source:
        print("[TJBot] Ouvindo ditado médico...")
        audio = recognizer.listen(source)
        try:
            texto = recognizer.recognize_google(audio, language="pt-BR")
            print(f"[Médico Disse]: {texto}")
            return texto
        except sr.UnknownValueError:
            print("[TJBot] Não entendi o áudio.")
            return None
Resposta em áudio do TJBot ao médico (speaker.py)
import pyttsx3

def falar(resposta_texto):
    engine = pyttsx3.init()
    engine.setProperty('rate', 160)
    engine.setProperty('volume', 1.0)
    print(f"[TJBot Falando]: {resposta_texto}")
    engine.say(resposta_texto)
    engine.runAndWait()

if __name__ == "__main__":
    falar("Ficha médica do paciente preenchida com sucesso!")
Script principal no Raspberry Pi acionando servo e LED (main_raspberry.py)
import RPi.GPIO as GPIO
import time

SERVO_PIN = 18
LED_RGB_RED = 22

GPIO.setmode(GPIO.BCM)
GPIO.setup(SERVO_PIN, GPIO.OUT)
GPIO.setup(LED_RGB_RED, GPIO.OUT)

def acenar_braco():
    pwm = GPIO.PWM(SERVO_PIN, 50)
    pwm.start(7.5)
    time.sleep(0.5)
    pwm.ChangeDutyCycle(12.5)
    time.sleep(0.5)
    pwm.stop()

def ligar_led_processando():
    GPIO.output(LED_RGB_RED, GPIO.HIGH)

if __name__ == "__main__":
    ligar_led_processando()
    acenar_braco()
    GPIO.cleanup()
Módulo de IA para extração e preenchimento de ficha estruturada (ai_fill.py)
import json

def processar_fala_para_ficha(transcricao_fala):
    prompt_ia = f"""
    Extraia os dados médicos da seguinte fala e estruture em JSON:
    '{transcricao_fala}'
    """
    ficha_estruturada = {
        "sintomas": ["Febre alta", "Dor de cabeça"],
        "diagnostico_provavel": "Gripe Forte",
        "medicacao_prescrita": "Paracetamol 500mg de 8/8h"
    }
    return json.dumps(ficha_estruturada, ensure_ascii=False, indent=2)
